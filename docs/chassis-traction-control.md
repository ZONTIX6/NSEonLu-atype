# 起步空转与制动滑动：防滑控制试验

本版面向起步/急加速时的驱动空转，以及松杆停车/换向时的车轮抱死趋势。控制已经接入真实轮速 PID、电流限制、功率限制和 CAN 发送链路，但地面防滑收益尚未实车验证。新参数都是试验初值。

它使用现有 FUSED 平移速度与固定底盘 IMU 的独立角速度，按各轮滚动方向重建正常滚动速度，再和各轮原始转子 RPM 比较。不能把融合速度当作独立地速：现有滤波也使用轮速，共同持续打滑、全车侧滑、IMU漂移或滤波拒绝时可能识别不出真实滑动。本版不是已经验收的汽车 ABS，也不能恢复超出轮地摩擦能力的轨迹。

## 1. 实现与开关

路径：`车身指令 → 轮速PID → 防滑处理 → 既有功率/电流限制 → 停车门控 → CAN`。直接力控后端和采集板不启用本功能。

| CHASSIS_TRACTION_MODE | 行为 |
| --- | --- |
| 0 | 默认关闭，保留原控制。 |
| 1 | 计算、记录空转/抱死判定及降扭建议，不修改 PID 电流或积分。 |
| 2 | 持续空转时撤掉该轮同向驱动电流；抱死趋势时减小该轮制动/反转请求；随后逐步恢复。 |
| 3 | 在模式2上，允许对持续空转轮新增有限的反向制动电流；不要求轮子倒转。 |

配置在 `config/30_velocity_observation/chassis_traction_config.h`。模式2/3要求显式 `CHASSIS_TRACTION_CALIBRATED=1`；该值是操作者完成测试后的声明，不是自动标定或实车通过证明。

主要初值：

- 判定阈值为 `0.25 + 0.20 × |预计轮缘速度| + 延迟容许量`，单位 m/s。它不是固定20%的滑移率控制。
- 延迟容许量为 `8 × 速度估计年龄 + 20 × 轮子旋转力臂 × max(速度年龄, gyro年龄)`；年龄以秒计。这些是误差容许斜率，不是已测车辆加速度上限。历史平移向量按公共wz符号转到当前车体系，不预测真实加减速。
- 新 CAN 样本连续确认20 ms才进入；低于半阈值连续40 ms后退出；驱动/制动比例约200 ms恢复。重复读取同一个 CAN 样本不增加确认时间。
- 空转识别低速界限为轮缘0.30 m/s；抱死减制动要求预计轮缘速度至少0.40 m/s。接近停止时退出抱死处理，保留普通速度环停车能力。
- 模式3新增制动最大300个 DJI 电流命令刻度，并受该轮速度PID最大输出进一步限制；增益为1000刻度/(m/s)。300不是300 A。已有更强的正常制动请求不会被本分支加强。
- 任何轮反馈超过20 ms、任一轮不在线/未使能、融合或gyro超过40 ms、估计非FUSED、目标被调参路径替换、控制超时或停车时，清除防滑状态并撤销干预。基础控制和原有停车门控继续决定输出。
- 实际修改电流的周期清零对应轮速PID积分项，避免恢复时累积驱动/制动请求。现有车身速度修正没有积分，防滑限流位于其下游。
- 模式2/3存在新鲜的实际干预时，向功率外环发送暂停正向补偿学习的标志，并禁止自旋策略继续提速；模式1不改变这些行为。

先核对 `CHASSIS_TRACTION_GYRO_Z_SIGN`。它把固定IMU安装旋转后的Z角速度映射到公共轮速wz符号，只允许+1/-1。旋转符号错误会把正常自旋当作打滑；安装四元数仍沿用远端IMU配置。

## 2. 构建与固件身份

在工程根目录执行：

```powershell
# 第一轮：记录判定，控制输出保持原样。
.\scripts\build-traction.ps1 -Mode 1

# 相同配置的关闭基线。
.\scripts\build-traction.ps1 -Mode 0

# 完成轴向、误判和限扭试验后，再显式构建主动版本。
.\scripts\build-traction.ps1 -Mode 2 -Calibrated
.\scripts\build-traction.ps1 -Mode 3 -Calibrated
```

脚本只构建，不烧录。它读取当前主板预设，保留功率、自旋、原车身速度试验等选项，在 `build/traction-modeN/` 生成独立预设、ELF/HEX/BIN和带ELF SHA-256的 `traction-build.json`，不修改日常双板烧录预设。生成预设固定主板为单板速度控制、远端固定IMU融合，并选择VOFA防滑档。采集板仍使用原来的IMU发送固件。

需要预览构建选项时用 `-Action Show`。实际试验保存生成预设、JSON、两板固件身份和参数头副本。通过其他烧录入口加载时必须选择对应目录的ELF，不能把日常主板输出当成本次试验产物。

## 3. 你需要准备的测量

最低配置是现有四轮编码器、固定底盘IMU和同步VOFA日志，加一个固定机位视频：镜头尽量垂直地面，画面内放长度标尺和固定地面点，车上标出底盘中心/方向。优先用120 fps或更高帧率；记录实际帧率和长度分辨率。

先做直行/横移，暂不叠加小陀螺。视频跟踪同一个车体点，得到独立的车身位移、速度和朝向，再和轮速比较。仅用轮速积分、融合曲线是否平滑、往返是否回到起点，无法证明防滑收益。条件允许时可用视觉定位、外部光流/测速设备代替视频。

每次记录：地面材质、轮胎状态、载荷、电池/电容状态、功率上限、方向、目标速度和固件身份。保持PID、功率、静态漂移/相位补偿参数一致；交替做关闭/开启试次，每种条件至少5次。手动遥控应同时检查记录中的轮速目标，确认命令幅度和持续时间相近。

## 4. 按这个顺序实车测试

| 顺序 | 动作与初始范围 | 必须核对的证据 |
| --- | --- | --- |
| T0 轴向/尺度 | 沿用原卡尔曼原始观测档，断驱动手推前后左右、双向转动；再逐轮低速架空核对电流/转速符号。测量负载下轮径和19:1减速比是否正确。 | 前后/横向符号、LF/RF/LB/RB顺序正确；gyro映射后的wz与真实旋转、轮速wz同号。架空只验证链路，不签地面防滑收益。 |
| T1 静止与正常滚动 | 模式1，静止30 s；普通地面前后、左右匀速，按约0.3、0.6、1.0 m/s逐档试验。 | 估计/gyro持续新鲜；正常滚动时预计轮缘与实测轮缘一致；无空转/抱死证据时持续判定计数不应增长。 |
| T2 正常起停/换向 | 模式1，同样三档速度做起步、松杆停车、低速前后换向，每方向至少5次。 | 对齐视频，确认正常加减速延迟不会被误判；检查低速截止、方向跨零、确认时间和恢复过程。先用这些数据调整阈值，不能只看有无掩码。 |
| T3 急加速空转 | 模式1先记录实际会空转的地面/加速动作；再交替模式0/2比较，最后才比较2/3。先低速，逐步增加命令幅度。 | 空转轮的轮速明显领先独立地速；判定轮正确；同向电流被减少；模式3新增电流与该轮转速乘积为负；最终CAN电流仍受功率限制。 |
| T4 急停/抱死 | 从约0.3 m/s起，逐步到0.6、1.0 m/s，松杆停车；交替关闭/模式2，必要时再比较3。 | 视频显示车身仍移动时，车轮是否过早接近停止；若发生抱死趋势，制动电流应被减小。比较停车距离/时间、横偏和轮速恢复，不以“制动电流越负”作为通过条件。 |
| T5 换向 | 先约+0.3→-0.3 m/s，再逐步提高，包含前后、左右。 | 车身尚未停下时不持续施加使轮子抱死/提前反转的请求；跨零后能恢复反向驱动，无反复抖动。视频与每轮电流同时核对。 |
| T6 不同抓地与载荷 | 固定的低摩擦试验面、单侧抓地差异、正常载荷变化，重复T3～T5。 | 收益是否可重复；是否发生漏判/误判或方向突然偏转；共同持续打滑可能超出此估计器能力。 |
| T7 故障与门控 | 低速下中断/恢复远端IMU；检查轮反馈失效、遥控停车和零力模式。 | 防滑退出，旧反向电流不被保持；原有无效轮/停车门控仍生效；恢复后重新确认，不继承旧判定。零力/急停门控优先，不由防滑强制保持制动。 |
| T8 自旋与实时性 | 前面通过后，才加入双向小陀螺、平移和不同转速。实测任务耗时、周期抖动、栈余量。 | 不把正常旋转、滤波延迟或相位补偿当作打滑；轴向/gyro符号再次成立；没有新增超时、频繁退出或功率异常。 |

若模式1在正常急起急停中频繁判定，先查时间配对、gyro符号、轮径和估计延迟，再用实测数据确定阈值。日志中频繁失效时先解决数据质量，不能靠放宽超时掩盖问题。模式3还要记录供电母线电压、电容状态和电机温度，检查新增制动的再生/电流影响；必要时同时保存原有USB/功率观测。

0.3 m/s等低速档主要验证轴向、跨零和门控；可能尚未达到轮缘最低速度或包含延迟余量的进入阈值。只有出现可独立确认、超过进入条件的真实滑动时，才评价主动干预收益。

## 5. 什么才算改善

分别记录每次的实际地速、轮缘超速/欠速持续时间与峰值、起步到达相同实际速度的时间、停车距离/时间、换向完成时间、横向偏差，以及最终电流和功率。先用视频确认真实打滑，再统计模式1的误判/漏判。

通过依据应同时包括：真实空转/抱死持续时间减少、起步或停车表现改善、正常抓地工况没有新增持续误干预/抖动、故障门控通过。不以“负电流出现”“干预计数增加”或“融合更平滑”单独签通过。先确定测量分辨率，再比较至少5次试验的分布；本版不预先承诺百分比收益或停车距离。

## 6. VOFA档3：schema 10，72路

UART7，JustFloat，20 ms最新快照。轮序始终LF/RF/LB/RB；速度为m/s，RPM为电机转子rpm，电流为DJI刻度。短于20 ms的事件可能没有单独一行，累计计数用于补充证据，不能由本档重建每个1 kHz周期的峰值/反应延迟。

| I通道 | 含义 |
| --- | --- |
| 0 | schema=10 |
| 1～2、3～4 | 主板毫秒时间、遥测尝试序号，各拆为hi16/lo16 |
| 5、6、7 | 模式、有效位、退出原因 |
| 8～11 | 空转、抱死、实际电流改动、新增空转制动掩码 |
| 12～13 | 电机周期累计数 |
| 14～15、16～17 | 实际电流干预周期数；其中四轮使能且CAN提交被接受的周期数 |
| 18、19 | 平移参考/gyro年龄，ms；未知或不可用为-1 |
| 20～23、24～27 | 正常滚动预计轮缘速度；原始RPM换算的实际轮缘速度 |
| 28～31 | 沿预计滚动方向的轮缘速度差，正值表示超速、负值表示欠速；预计速度很小时使用空转残差 |
| 32～35、36～39、40～43 | PID原始电流、防滑建议电流、最终CAN电流 |
| 44～47、48～51 | 实际使用的轮速目标rpm；反馈电流 |
| 52～55、56～59 | 每轮本周期进入阈值；当前请求方向的衰减比例 |
| 60、61、62、63 | 有效功率上限、功率计功率、最终使能轮掩码、快照年龄ms |
| 64～65、66～67 | 存在空转判定/抱死判定的电机周期累计数（包含模式1） |
| 68～70、71 | 输入参考vx/vy/wz，wz为rad/s；gyro符号配置 |

有效位I6：bit0有快照，bit1快照不超过20 ms，bit2该快照防滑输入有效，bit3四轮CAN提交被接受，bit4标定声明，bit5功率快照新鲜且控制版本匹配。旧值可能保留，必须先检查有效位。bit3及累计数表示软件提交证据，不证明电调执行或地面收益。

I7原因：0可计算，1关闭，2配置无效，3控制/目标门控，4无FUSED参考，5参考超龄，6轮数据异常，7周期异常。判定有效且掩码为0表示当前未确认打滑，不等于功能关闭。

uint32还原为 `hi×65536+lo`，区间增量使用uint32回绕差；不把开机以来的累计数直接当成本次试验数量。模式0不采集防滑快照，其掩码为0、年龄未知；轮速/功率可同时由原USB采集。模式1与2/3才有本档完整防滑输入。
