# 自适应自转功率与缓冲控制

更新：2026-10-24。缓冲增补现已恢复为原 C 板的需求触发规则；非零起转及功率保护保留。对应实施记录见 [需求增补计划](superpowers/plans/2026-10-24-c-board-demand-buffer.md)。软件验证不代替实车验收。

## 生效范围

`CHASSIS_FOLLOW_MODE` 默认 0，保留原车身跟随云台行为。缓冲开启时，自适应、固定、正弦及普通运动复用同一个需求增补计算；超级电容保留输入反馈和电容状态约束。显式 `CHASSIS_SPIN_MODE` 优先于旧 `CHASSIS_SPIN_ADAPTIVE_ENABLE`。

## 需求触发增补

输入包括有效裁判限功率 L、功率计实测、限流前电流请求的预测功率总和，以及缓冲能量保守下限 E。需求 Q 取预测功率与有效实测功率的较大值。只有 Q 大于基础目标 `0.98 * L`，且驱动需求、反馈、计量、能量估计和时间连续有效时，才申请增补。

**不再要求实测达到基础功率，不等待基础到达确认，也没有自转专用的 30 J 准入或能力锁存释放窗口。** 模型限流或预测限流期间，限流前需求仍可申请可用缓冲；电流、转速和实测快保护继续约束最终输出。

沿用 C 板普通预算计算，eta 为安全系数：

```text
需求余量 = max(0, (Q + demand_margin) / eta - L)
能量余量 = max(0, (E - recovery_enter) / prediction_window)
预测余量 = max(0, (E - hard_floor) / guard_window - power_margin)
预算增补 = min(需求余量, 能量余量, 预测余量, max_boost)
名义预算 = L + 预算增补（上升限斜率，下降立即生效）
实测功率目标 = eta * 名义预算
实测保护上限 = 名义预算（电容路径另受电容可用功率约束）
```

自转遥测的增补请求/获准量按实测目标口径报告，为名义预算增量乘 eta。预算增补与模型慢环补偿是不同的量：补偿不能修改批准的实测保护上限。

例如 L=50 W、实测 42 W、预测需求 60 W、需求余量 5 W 且能量充足时，名义预算趋向 `65/0.98=66.33 W`，目标趋向 65 W，目标口径的缓冲增补为 `65-49=16 W`。实测无需先达到 47 W；若预测需求也未超额，则仍保持基础预算。65 W 是计算目标示例，不是实车输出保证。

需求消失、制动、反馈失效、计量过期/无效、裁判缓冲无效或周期异常会撤销相应增补。健康需求恢复且计量连续有效后可重新申请，不重新等待基础功率确认。低能量回充和预测底座始终优先。

## 逐轮闲置额度回收

`PowerModelApply` 保留小误差均分、低预算误差比例和高预算基础保留功率的初始分配。在总额度内，回收其他轮子用不完的额度，按未满足的功率缺口分给有需求的轮子。需要量按硬限流后的原始预测、零电流损耗与零三者的最大值计算，避免借出零电流损耗或把负预测作为额外供电能力。

49 W 有效预算、四轮需求 10/6/15/11 W 的最小同周期测试中，旧算法将第三轮压到 12.25 W，最终合计 39.25 W；修复后四轮需求全部满足，合计 42 W。49 W 预算、需求 10/6/40/11 W 时，分配结果为 10/6/22/11 W，仍受 49 W 总限额约束。电流硬限幅、实测快保护及最终预测保护继续生效。

生产功控模块的阶段 0/1/2/3 均验证：前一用例不再误报 `base_limited`，后一用例仍报告真实限流。这能解除逐轮闲置配额引起的升速阻塞；自适应仍可能因功率死区、跟随、硬速度、制动或数据失效停止增长，修复不保证每种负载都消耗缓冲。

## 当前保护参数与起转

本次对齐增补计算和准入规则，保留 A 板现有通用保护参数，不覆盖成 C 板旧参数：

| 参数 | 当前默认值 |
| --- | --- |
| 回充进入 / 退出 / 预测硬底座 | 10 / 20 / 5 J |
| 退出回充确认 | 100 ms |
| 能量释放时间 / 预测保护窗口 | 0.25 / 0.3 s |
| 名义预算增补上限 / 上升斜率 | 60 W / 1200 W/s |
| 结算延迟 / 能量余量 / 功率余量 | 0.1 s / 3 J / 5 W |
| 自适应功率误差增益 | 80 Wz/(W·s) |
| 自适应 rise / fall | 3600 / 2400 Wz/s |
| 自适应功率低通 / 后续升速确认 | 50 / 50 ms |

健康进入自适应自转时直接使用生效的 min_wz 建立非零需求，源码默认 1000 Wz；后续才按斜率、跟随及功率余量增长。退出、禁用、反馈失效仍输出零，保护拒绝增长时不强拉初始目标。初始目标服从有效完整校准组合中的硬速度边界。Wz 是现有指令单位，不是整车 rpm。

普通候选目标保留逐轮 500 rpm 领先边界；单独确认的新反馈加速趋势可按 25% 上升率有界增长。持续落后时停升并按 fall 回收。整车 `max(0.05 圈/s, 5%)` 跟随及候选领先门槛用于接近软上限或已有扩展资格的严格区域。

预测 guard 使用模型瓦数，换算物理上限时允许计入已经实际应用的有界正模型补偿；实测快保护仍直接比较未加补偿的批准上限。超限、计量过期/关闭、反馈失效、制动或周期异常立即撤销正补偿，原模型预算最多 +8 W 的边界保留。

有效旧 Flash 参数仍优先于源码默认。非零初始值取当前 min_wz，旧 rise 不会自动变为 3600。通过在线调参 GET 核对生效值；固定、正弦普通 rise 默认仍为 1200，扩展区为 600 Wz/s。字段数量、模式编号和 Flash 格式不变。

## 遥测与上限

CSV v5 保留原 127 列及 v1–v4 兼容。下列阶段仅报告当前自适应直供预算状态，阶段本身不再批准增补：

| spin_power_phase | 含义 |
| --- | --- |
| 0 | 非自适应直供路径，使用普通预算 |
| 1 | 基础预算，当前没有超额需求增补 |
| 2 | 有效需求正在申请缓冲增补 |
| 3 | 低能量或预测底座触发回充 |
| 4 | 数据降级，撤销自转增补及新的升速 |

`spin_base_power_cw` 仍为 `eta * L`；增补请求、获准量与目标使用一致物理瓦数口径。`spin_base_confirm_ms`、`spin_capability_latched`、`spin_capability_release_ms` 保留协议位置并为零。预算上升不代表实际功率已跟上，应同时观察实测功率、目标/实际轮速、模型修正与保护原因。

软上限扩展继续默认关闭。开启需完整配置有效的 hard_wz、body_hard_rps、wheel_hard_rpm，且 hard_wz 不低于软上限。接近软上限时，功率余量、整车及逐轮严格跟随、保护健康和小平移条件按新功率/反馈样本确认 200 ms；扩展区最大上升率 600 Wz/s。任何硬边界优先，实际超速会撤销增长并降低需求。预算层不再保留自转能力锁存，速度/电流限制仍在控制器与电机输出层生效。

编译项保持 `CHASSIS_SPIN_EXTENSION_ENABLE`、`CHASSIS_SPIN_HARD_WZ`、`CHASSIS_SPIN_BODY_HARD_RPS`、`CHASSIS_SPIN_WHEEL_HARD_RPM`、`CHASSIS_SPIN_EXTENSION_RISE_RATE`，不扩展 16 项运行时自转参数。整车反馈/网页为 rpm，编译项 BODY_HARD_RPS 与内部阈值仍用圈/s，接入显式换算。

## 构建与实车验证

```powershell
make -j8 PROFILE=atype-direct BUILD_DIR=build/demand-buffer-direct CHASSIS_SPIN_MODE=1
```

实车需记录同电压、同地面下的预测未限流需求、预算/目标/实测功率、缓冲下限与保护原因，核对未达到基础实测功率时可按需求增补，以及无超额需求、低能量、限功率突降和失联时的撤销。有限缓冲只支持短时超限；尚未执行烧录或实物操控。
