# 速度路径预测功控：软件实现与验证记录

更新：2026-10-29。设计依据：[架构方案](superpowers/specs/2026-10-28-predictive-power-supercap-architecture-design.md)。

## 本次交付和启用方式

速度控制的发送结果门控已经生效；新增预测算法通过独立影子模式接入。影子模式计算候选、记录状态，不改写现有 PID、输出电流或超电请求。默认构建仍为原速度后端。

```powershell
# 原速度控制，独立构建目录
make PROFILE=atype-vehicle BUILD_DIR=build/predictive-legacy -j8
# 速度路径影子计算，Stage 0–3 的意义不变
make PROFILE=atype-vehicle BUILD_DIR=build/predictive-shadow CHASSIS_PREDICTIVE_POWER_MODE=1 -j8
```

`CHASSIS_PREDICTIVE_POWER_MODE=0` 为旧控制，`1` 为影子；`2` 表示尚未发布的接管模式，会报编译错误。没有烧录固件，也没有更改 F334 固件。按用户要求，力控不在后续实施和放行范围内。

完整方案尚不能称为已上车完成：10 变量 QP MPC、带延迟测量回溯的状态估计、离线辨识流水线、在线 RLS、协议强确认和控制权接管仍未交付。当前提供可运行和验证的软件基础、保守能量规划及影子接入，不把主机测试当作实车性能验收。

## 已接入的行为

- 速度需求增长要求本周期最终记录有效、CAN 提交成功且新鲜。失败发送不再继续支持裁判缓冲增补。
- 超电命令发送结果在应用发布控制快照前处理；失败当周期撤销增补、清除正向外环累积并禁止主动驱动，因为当前未配置经验证的旁路供电路径。后续成功发送只恢复旧协议受限流程，不等同于 F334 已执行请求。
- 功率计快照增加接收事件计数 `rx_sequence`，支持同毫秒多帧和计数回绕。
- 快层影子使用一份完整输入、配置和物理瓦特额度。无动态参数包时使用现有六项模型的保守凸包络；逐轮舍弃负常数/负线性项，防止某轮负预测抵扣其他轮消耗。该结果标记 `baseline_envelope=true`，不冒充动态预测。
- 有有效参数包时运行电流一阶响应、局部轮速预测及固定速度范围功率上界。所有电流为已说明的等效反馈单位，转速为电机转子 rad/s。没有凭空将原始反馈解释为安培。
- 带延迟模型只在历史覆盖整个延迟窗口、命令稳定、提交全部成功、模型/配置版本一致时准入。变化中的延迟队列暂不预测；不把最近提交命令当作已执行命令。
- 分配器在归一化变量上求解四维凸二次目标、单个凸二次功率约束和盒约束。固定次数乘子搜索，坐标迭代残差偏大时枚举最多 81 个面。整数候选再次检查盒约束、功率及原动态模型有效域。通用核心支持耦合目标；当前板级影子使用轮速跟踪、PID 偏离和历史命令惩罚，尚未标定平移/旋转权重。
- 慢层在应用上下文最多每 10 ms 计算一次直供缓冲影子计划，使用现有保守缓冲估计和可信需求。计划独立保留生成时间，快层只使用 20 ms 内、同配置的计划，并且只能收紧诊断候选额度。
- 双储能纯算法实现了 10 节点、5 块、总计 0.5 s 的原方程区间校验：高输入扣缓冲、低输入和高负载扣电容、低负载检查过充。规划器采用固定请求、常值额度的保守可行性搜索，**不是完整 QP MPC**。旧协议缺少可信焦耳和强确认时，板级适配不生成电容计划。
- 监督核心检查许可、故障、策略/模型/配置/能力版本、额度到期和 300 μs 时间门槛，回退候选也需复核。零驱动不满足被动损耗约束时明确报告无可行解。该监督核心尚不接管实际电流输出。

## 接口和状态

| 文件 | 责任 |
|---|---|
| `modules/predictive_power/power_prediction.*` | 参数校验和、动态预测、功率包络和有效域检查 |
| `modules/predictive_power/power_observer.*` | 有限最终命令历史、有效反馈去重、回绕/乱序检查、稳定延迟窗口 |
| `modules/predictive_power/power_allocator.*` | 四变量 QCQP、整数候选复核、迭代和残差 |
| `modules/predictive_power/energy_scheduler.*` | 区间能量递推、保留量/终端量、保守滚动规划 |
| `modules/predictive_power/power_supervisor.*` | 独立许可、版本、时效与可行性仲裁 |
| `modules/chassis_power/chassis_power_shadow.*` | 快层装配、物理单位转换、最终记录、原子诊断快照 |
| `modules/chassis_power/chassis_power_shadow_energy.c` | 速度策略侧慢层影子计划和独立有效期 |

`ChassisPowerShadowSetModel()` 校验参数并通过短临界区发布待用版本，快任务在周期边界切换。默认没有动态参数包；此 API 只配置影子计算，校验和不代表实测标定认可。参数中的误差界需要包含接收时间与采样时间差，当前观察器不是 EKF，也不宣称完成异步测量重放。

`ChassisPowerShadowGet()` 在最终 CAN 结果记录后提供完整快照，包括实际 dt、模型/配置/控制版本、原始测量功率、功率计事件计数、预测、量化候选、可行性残差、实际最终命令和提交结果。`elapsed_us/max_elapsed_us/overruns` 使用板上 DWT 测量新增快层耗时。`eligible` 只表示当前影子候选准入，不表示允许切换执行后端。

`ChassisPowerShadowEnergyGet()` 返回独立慢层计划、能量轨迹、生成时刻、配置版本和求解耗时；周期中的 5 ms 应用快照刷新不会重写计划生成时刻。未形成计划时 `plan.valid=false`。两个 getter 可供调试器或后续低频遥测读取；没有增加 CAN 帧或修改现有 CSV 协议。

## 回放

```powershell
python scripts/predictive-power-replay.py --model tests/predictive_power/synthetic-model.json --capture tests/predictive_power/synthetic-capture.csv --output build/synthetic-predictive-report.json
```

此示例仅验证工具链，全部为明确标注的合成数据，不能作为硬件收益证据。工具编译并调用本次生产 C 预测器；报告保存输入文件 SHA-256、源码提交、工作区脏标记、参数校验和、有效样本对、各类拒绝数量、RMSE 与功率上界最大违反量。无有效样本对返回非零状态。

真实输入 CSV 必须预先对齐采样时刻和负载侧计量边界。`sample_ms` 为统一 uint32 时基；`meter_sequence` 为接收事件序号；`submitted` 为 0/1；`load_w` 为同边界实测负载功率；`current0..3` 为标定的等效电流；`omega0..3` 为转子 rad/s；`command0..3` 必须为最终 int16 命令。一次拒绝会断开测量状态链，乱序或重复帧不能倒退有效序号或污染后续初态。长间断不连线推测；非零延迟仍要求历史命令稳定。此工具不自动把旧捕获格式的接收时间推断成采样时间，也不拟合参数。
