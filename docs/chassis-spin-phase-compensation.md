# 小陀螺平移相位补偿

仅速度后端的 `CHASSIS_ROTATE` 使用。以云台为前方输入平移时，旋转底盘中的轮速目标持续变化，轮速响应滞后会产生侧向分量。

2026-11-19 两次记录中，目标到四轮反算平移方向均约滞后 10.2°；前进速度约减半时，额外侧向速度从 0.222 降为 0.109 m/s。一次尺量前进 240 cm、右偏约 65 cm，对应起终点方向偏角约 15.2°，旋转速度约 1.08 圈/s，因此先试 39 ms。烧录 39 ms 后复测前进 320 cm、左偏约 22 cm，说明补偿方向正确但略过量；按两次实测插值，零偏点约 31–33 ms，当前默认收敛为 32 ms。

## 参数

修改 `config/02_chassis/chassis_config.h` 后重新编译主板，也可以通过 Make/CMake 同名参数覆盖。参数为编译期配置，不由旧 Flash PID/功控参数覆盖。

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `CHASSIS_SPIN_PHASE_COMPENSATION_ENABLE` | `1` | 0 关闭，1 启用小陀螺平移相位预测 |
| `CHASSIS_SPIN_PHASE_PREDICTION_MS` | `32.0f` | 角速度乘以此时间得到预测角，单位 ms；设 0 取消提前量 |
| `CHASSIS_SPIN_PHASE_MAX_DEG` | `25.0f` | 预测角绝对值上限，单位 ° |
| `CHASSIS_SPIN_PHASE_FILTER_MS` | `20.0f` | 相对角速度一阶滤波时间常数，单位 ms；设 0 取消滤波 |

32 ms 是根据两次实车终点偏差插值得到的下一次试验值；它不是测得的 CAN 延迟。不能从日志离线旋转向量就认定实车已经消除侧偏。

## 实现

`application/chassis/chassis_motion.h` 使用控制任务实际毫秒时间，对相邻 `offset_angle` 作最短圆周角差，得到相对角速度，再一阶滤波。由同一个相对角求导，避免直接使用与它符号相反的底盘 gyro/wz。预测角为：

```text
phase_lead_deg = clamp(relative_rate_dps * prediction_ms / 1000, -25°, +25°)
body_translation = R(offset_angle) * (R(phase_lead_deg) * operator_translation + static_trim)
```

相对角增长时提前角为正，相对角减小时提前角为负。相位旋转保持平移向量长度，前进、后退、横移和斜向平移均使用同一规则。静态漂移补偿仍按原实测角旋转，无平移输入时不因相位预测新增移动。

首次进入小陀螺或控制间隔超过 30 ms 时清除旧速度估计，首次提前量为 0；退出小陀螺、无效角度或无效预测参数时清零。角度跨 ±180°、毫秒计数回绕不会产生导数尖峰。角度冻结时估计速度随滤波衰减至 0。现有输入有效性、功率限制和输出许可继续负责下游控制门控。

补偿在评估平移轮速约束之前进入 `ChassisResolveMotion`，因此功控/自旋约束看到的就是实际采用的平移方向。它不重写原始 `offset_angle`、平移输入或旋转目标，不读取融合速度，也不改变其他底盘模式。直接力控后端没有接入本补偿。

## 构建与复测

使用现有主板配置构建：

```powershell
powershell -File scripts/build-board.ps1 -Action Build -Board 1
```

只需更新整车主板，独立底盘 IMU 采集板不需要因本改动重新烧录。

先沿原路线、相同输入重复前进 240 cm，记录右偏或左偏距离。仍右偏时小幅增加预测时间，变成左偏时减小；确认趋势后，再比较较低/原自旋速度、反向旋转、后退及横移。默认角度上限会在更高转速时截断，不能据此假设高转速补偿仍线性。

VOFA 原始相对角 `I97` 保持实测含义；补偿会体现在目标速度 `I23/I24` 中。后续分析不能再把所有目标相对当前云台方向的差异都解释为陈旧角度，因为其中已包含本次有意加入的预测角。现有 109 通道 schema 保持兼容。

主机测试包含正反旋转的延迟运动模型、跨圈角度、计时回绕、异常间隔重置、模式切换、静态漂移补偿隔离及关闭/零预测时间配置。最终轨迹效果须以烧录后的实测位移确认。
