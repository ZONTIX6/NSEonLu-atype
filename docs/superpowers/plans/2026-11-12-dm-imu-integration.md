# DM-IMU-L1 接入计划与完成记录

**目标：** 用 CAN2 上的 DM-IMU-L1 替代第二块采集板，按现有框架接入并删除废弃文件。

**架构：** CANRegister 注册主板 CAN2 接收端，独立纯 C 解码器提供 chassis_imu_sample.h 公共快照，runtime 负责初始化与临界区读取。现有底盘融合/遥测继续消费同一接口，本地云台 INS 保持原职责。

**约束：** CAN2 / 1 Mbps，MST_ID 配成 0x11，主动输出 accel/gyro/quaternion，Euler 可选。模块没有源时间戳和组序号，首片接收时刻仅作估计。完整组最大跨度10ms；相邻已发布首片间隔至少18ms，使名义100Hz输入约50Hz发布并容忍±1ms抖动。方向与去重力须上板验证。沿用schema3/72列，bit19标识DM。融合只观测，不进入控制。
