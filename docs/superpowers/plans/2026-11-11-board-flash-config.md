# 两块 A 板构建与烧录切换

目标：在 `config/00_flash/board_flash_config.h` 用一个 `1/2` 选择值切换 CAN1 主整车板与独立 IMU 采集板，并保证构建、输出路径和烧录参数一致。

方案：配置头保存板号、烧录器及两组完整编译选项；PowerShell 入口读取纯常量配置，在调用 Make 前传入选项，因此条件编译、源选择和数值编译标志同步生效。两块板分别输出到 `build/board-1-main`、`build/board-2-imu`。新增明确命名的 VS Code 任务，不改变原有手动 Make/CMake 和 F5 调试入口。
