# 集中配置整理实施计划

**目标：** 在根目录 `config/` 按用途集中工程配置、调参宏和 PID 默认值，使参数位置可直接从文件名识别。

**方案：** 保持数值、条件编译和运行时覆盖顺序；头文件承载宏和声明，源文件承载有类型的初始化数据。原配置头保留相对路径转发入口，协议常量、算法实现和运行状态留在所属模块。

**技术栈：** C11、STM32F427、Arm GNU、Make、CMake、主机 GCC 测试。

## 约束

- 保留现有 `Inc/board_config.h` 中 VOFA 模式的未提交改动，迁移后仍单独留在工作区。
- 不改参数值，不烧录，不推送；验证后仅提交本任务改动。
- 厂商 HAL、FreeRTOS、寄存器/协议定义不属于本次业务调参整理。
