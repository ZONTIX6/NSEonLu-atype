# 小陀螺 yaw 积分限幅：3000 调至 9000

来源：`D:/Downloads/小陀螺启动复测.csv`，SHA256 `81518a4519a998eccf811c1d3e164229e9dbfb4c5c770c890277a4762176b4fb`。原文件保持不变。

schema 7、108 通道，4543 条记录，持续 92.541 秒，8 次完整观测到的自旋段。每次以前 1 秒航向均值为基准，以首次观测到自旋后 [1,1.9) 秒作统一窗口，保留每条原始记录，不对缺口插值。

- yaw 目标全文件为 -1.053580～-1.053577°，变化仅 0.000003°。
- 8 次统一窗口共 352 条控制记录，积分均为 +3000，控制标志均为 79：使能、尝试 CAN、邮箱接受、速度环已计算、积分到限；速度环/角度环总输出限幅未触发。
- 各试次等权平均：头部相对基准偏差 -10.624636°，相对目标跟踪误差 +10.615859°，最终命令 7241.911245。

- Kp 角度=8、速度=50，因此约 10.6° 误差提供约 4240 命令，加 3000 积分后与实际输出一致。对稳定窗口按 `50×[8×(目标−航向)−gyro]+Iout` 复算，单条最大绝对残差不足 9 命令刻度。
- 上述证据支持先解除速度环积分限幅这一持续误差来源。扰动力矩的机械来源和新参数的实际效果仍待验证。

### 数据限制

全部数据数值有效，无重复帧、重启/倒序；I5=2015，云台/控制数据均有效，控制年龄最大 5 ms。所有帧包含 FIFO 溢出粘滞位。本段捕获序号缺 111 条，共 111 个单条缺口（端点间记录的约 2.39%）；唯一滤波调用之间缺 98 次。不能声称完整连续，或把缺口全归为无线丢包。

第 1、2、5、8 次入口前存在序号缺口，真实切换可能发生在缺失记录内。记录负峰 -11.29～-13.00° 是已记录极值，不能声称真实峰值。稳定窗口仍每次有 43～45 条有效记录，积分全到限的重复证据不依赖缺失记录。
