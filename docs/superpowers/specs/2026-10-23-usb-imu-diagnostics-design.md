# USB IMU 与底盘跟随诊断

## 范围与现场结论

用户要求在现有 USB 网页加入 IMU，并排查旋转 A 板时 M3508 转速不变。现场连接为 A 板、一个 M3508 和 DBUS 遥控器；用户明确选择保留整车跟随逻辑，只补网页诊断。

`CalcOffsetAngle()` 使用云台 Yaw 电机单圈编码器角度减去 `YAW_ALIGN_ANGLE`，底盘跟随输出为该相对角度的限幅比例控制。板载 IMU 的绝对姿态不直接参与这个跟随量，因此单独旋转 A 板不会改变跟随角度。不能据此把整车算法改成 IMU 直接驱动单电机。

## 方案

仅增加网页静态展示无法取得固件尚未上报的 IMU；另开独立串口消息会增加样本关联和导出复杂度。因此沿用现有快照、50 Hz CSV 和图表机制，增加 CSV v2，网页兼容 CSV v1。

固件通过 `INSGetSnapshot()` 取得完整快照，上报有效位、样本年龄、Yaw/Pitch/Roll/累计 Yaw、三轴角速度和三轴加速度。使用现有单位：角度 °、角速度 °/s、含重力的机体系加速度 m/s²，全部乘 1000 传输。年龄超过 10 ms 或任一数值非有限时 IMU 无效；从未发布姿态时年龄为 UINT32_MAX。快照增加只读 `has_sample`，保留失效后的最后姿态和真实年龄，包括 HAL tick=0 的情况；转换在独立 IMU 遥测适配函数中执行。增加底盘快照的实际 `offset_angle`，只读上报为 `chassis_offset_mdeg`。

保留 v1 的前 72 列，v2 尾部依次增加 `imu_valid,imu_age_ms,imu_yaw_mdeg,imu_pitch_mdeg,imu_roll_mdeg,imu_yaw_total_mdeg,imu_gx_mdps,imu_gy_mdps,imu_gz_mdps,imu_ax_mmps2,imu_ay_mmps2,imu_az_mmps2,chassis_offset_mdeg`，共 85 列。缓冲仍为 2048 字节，测试最坏行长。版本与表头必须匹配。旧固件显示“固件未提供 IMU”，其原有数据正常展示；混合版本导出统一为 v2，旧记录 IMU 无效，跟随角用 −2147483648 表示未知并在网页留空。

监测页沿用现有卡片：IMU 数值表和三张姿态/角速度/加速度曲线；累计 Yaw 可选，默认关闭以免压缩姿态曲线。全部复用选择、暂停、放大、历史与悬停。底盘区增加实际跟随角和说明，帮助区分板载姿态与编码器输入。不改 PID、跟随算法和任何电机使能保护。

## 验证

Node 测试覆盖分片、v1/v2、负值缩放、无效/过期、版本错配、CSV 导出与旧字段兼容；C 测试核对顺序、极值行长与 10 ms 新鲜度；跨端测试解析真实 C 输出。浏览器验证无数据、演示、旧/新模拟串口、暂停/放大、导出及 320 px 窄屏。构建遥测与 USB 视觉固件。实机枚举和轴向核对需要用户烧录后完成。
