# 数据实例指针索引

用户进一步明确：要查找实际保存数据的结构体实例指针，而不仅是结构体类型。沿用已确认的中文用途、成员反查、源码位置和一键更新要求。

主入口新增 `docs/data-instance-index.md`，由 `scripts/generate-data-instance-index.py` 生成；类型索引作为字段定义的关联资料。原 Windows 一键更新脚本同时更新两份索引。

- 主表列文件级实例指针、指针数组与实际结构体对象，也收录函数内 static 持久实例。普通局部临时变量分开列出，不将函数参数、函数返回声明、结构体字段声明误当作独立的数据入口。
- 每个入口提供中文用途、变量名/作用域、指向或保存的类型、static/extern 属性、声明位置、初始化表达式与同作用域解析到的直接赋值位置。
- 成员反查展开真实访问路径，例如 `motor_lf->measure.speed_aps`、`power_meter->status.power_w`；无指针的对象则给 `state.field` 与 `&state`。数组用 `[0]` 演示有效索引表达式并注明示例；指针别名要保留其指针层级。
- 嵌套数据沿结构体/联合体成员递归展开；遇到指针环终止并明确显示环，不能生成无限或错误路径。同名/条件分支存在多个候选定义时标明候选，不能任选一个冒充确定结果。
- 从声明自动识别保存实例的变量；赋值证据只反映源码直接赋值，不推断任意函数的副作用或实际运行地址。字段声明和变量声明的宏展开能力以文档明确的范围为准。
- 类型查找优先使用同文件/同目录定义；测试代码优先使用本测试套件的定义，正式项目入口不借用其他测试桩的同名类型。匿名对象的显示名称不是可用于声明变量的 typedef 名称。
- 函数参数、普通局部变量、primitive typedef 与 for 初始化声明参与遮蔽判断；控制条件中的等号不会被误当作结构体初始化。跨条件分支的函数调用前缀保留共同结束括号。
- 指针/数组操作按各自声明符及 typedef 链组合，包含内联 `typedef struct { … } State, *Handle`、数组别名和数组指针；不能把指针别名当作值对象生成错误的 `.` 路径。
- 扫描范围沿用全部展开的仓库 C/H 源码，按项目代码、便携副本、第三方库和测试来源区分。源码不会因生成索引而改变。

实现复用原索引的词法扫描、类型/别名集合、源码位置与 Markdown 转义。使用标准库和原子输出；测试真实声明语法、作用域遮蔽、初始化、指针数组、匿名结构体、多层成员路径、递归环、别名指针和 CLI 更新检查。
